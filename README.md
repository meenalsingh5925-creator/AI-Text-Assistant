# AI-Text-Assistant
An interactive AI application build using Hugging Face Transformers and Gradio.

## Features
- Sentiment analysis using DistilBERT
- AI text generation using GPT-2
- Interactive Gradio interface
- Example prompts for quick testing

## Technologies
- Python
- Hugging Face Transformers
- GPT-2
- DistilBERT
- Gradio
- Pytorch

## How to run 
```bash
pip install -r requirements.txt
python app.py
